# NotesPilot downloads

**NotesPilot** takes notes for every call on your Mac, with no bot in the meeting. Works with Zoom, Google Meet, Microsoft Teams and any other call app. Private mode keeps everything on your Mac.

**[Download the latest NotesPilot.dmg](https://github.com/IdeaSolved/notespilot-releases/releases/latest/download/NotesPilot.dmg)** · [notespilot.ai](https://notespilot.ai) · [Release notes](https://notespilot.ai/changelog)

Requires macOS 26 Tahoe or later on a Mac with Apple silicon.

## Install

1. Download `NotesPilot.dmg` from the [latest release](https://github.com/IdeaSolved/notespilot-releases/releases/latest).
2. Open it and drag **NotesPilot** into **Applications**.
3. Open NotesPilot from Applications. It lives in your menu bar.

NotesPilot updates itself. You only download it once.
